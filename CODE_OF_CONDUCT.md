# Code of Conduct

Claude Code Compass is a community project. We want participation to be welcoming, respectful, and focused on improving the directory.

## Expected behavior

- Be considerate and respectful when discussing ideas, code, and repository listings.
- Offer constructive feedback and accept feedback in good faith.
- Make room for differing viewpoints and experiences.
- Keep discussions relevant and avoid sharing private information.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, deliberate disruption, doxxing, and publishing another person's private information without permission are not acceptable.

## Moderation

Maintainers may edit or remove content and may limit participation when needed to address harmful behavior. To report a conduct concern, contact the repository maintainers privately through GitHub rather than posting sensitive details publicly.

This policy applies in project issues, pull requests, discussions, and other spaces used for project work.
